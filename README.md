**App Description**

This is a PWA I vibe coded to manage and keep track of my shifts at the non-profit cooperative I was working in. The app run on a Netlify server.
It helped me to calculate my gross and net earnings, classify my shifts, and export reminders via `.ics` calendar on my iPhone.
I implemented few features in order to keep it as functional, reliable and smooth as possible.
